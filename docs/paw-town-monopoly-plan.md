## 一、项目背景与目标

基于现有大富翁玩法（v1.10.280 已 push），彻底升级为**萌系、少女心、猫猫狗狗主题**的大富翁游戏。

### 核心目标
- [ ] 萌系猫狗主题世界观
- [ ] 40 个地点，每个地点有专属立绘
- [ ] 8 个可选角色，每个角色有立绘 + 专属技能
- [ ] 丰富的道具卡系统（≥30 张）
- [ ] 房屋 5 级升级，每级不同外观
- [ ] Three.js 轻量特效（3D 骰子 + 粒子）
- [ ] AI 生图全包，用户负责抠图
- [ ] 先完成「四件套」，天气/任务/好感度后续迭代

## 二、主题与世界观

### 世界观
**帕瓦小镇（Paw Town）** 是一个由猫猫狗狗共同生活的梦幻小镇。镇长是一只橘猫，镇上所有的店铺、车站、公共设施都充满了萌宠元素。玩家扮演小镇的居民，通过买地、盖房、使用道具卡，争夺「小镇首富」的称号。

### 视觉风格
- **主色调**：天蓝色 + 暖黄色（清新萌系，非粉色主调）
- **辅助色**：奶油白、薄荷绿、蜜桃粉（仅点缀，不做主背景）
- **地产组色**：8 组保留区分色，但整体偏蓝黄谱系
- **风格关键词**：萌系、少女心、Q 版、圆润、高光、清新蓝黄
- **参考**：用户图 3 的游乐园俯视风格 + 图 2 的古风大富翁 UI 布局

## 八、核心玩法机制

### 1. 回合流程
```
开始回合 → 使用道具卡（可选）→ 掷骰子 → 移动动画 → 触发地块事件 → 买地/付租/抽卡/入狱 → 使用道具卡（可选）→ 盖房（可选）→ 结束回合
```

### 2. 胜负条件
- **破产淘汰**：现金 < 0 且无法变卖资产时出局
- **最终结算**：当只剩 1 名玩家未破产，或玩家主动点击「结束结算」时，按净资产排名

### 3. AI 行为设计（核心：像真人，不像机器人）

#### 3.1 回合节奏控制（用户看得清）
- **AI 回合最小间隔**：每个动作之间 1.2-2.5 秒停顿，让用户看清发生了什么
- **掷骰前**：显示「XX 正在思考...」1 秒 → 骰子动画 0.8 秒 → 停顿 0.5 秒 → 移动
- **移动动画**：逐格步进 150ms/格（比当前的 110ms 稍慢），每格有猫爪/狗爪脚印
- **落格后**：停顿 0.8 秒再执行结算，让用户看到落在了哪里
- **买地/盖房**：停顿 1 秒再决策，显示「XX 在考虑要不要买...」
- **收租**：停顿 0.5 秒，显示金额飘字动画
- **回合结束**：停顿 0.5 秒再切下一人

#### 3.2 AI 决策人性化（不总是最优）
- **买地概率**：不是固定阈值，加入 ±15% 随机波动
  - 有时现金充裕也不买（「留钱盖房」策略）
  - 有时现金紧张也硬买（「赌一把」策略）
  - 角色性格影响：可可（精明）更倾向买，雪花（高冷）更挑剔
- **盖房时机**：不总是垄断就立刻盖，有时等 1-2 回合
- **道具卡使用**：不总是最优时机用，有时留到关键时刻
  - 攻击卡 60% 概率立即用，40% 留着
  - 防御卡只在被收租 >¥100 时考虑用
- **不会完美交易**：二期交易系统加入「讨价还价」随机性

#### 3.3 AI 聊天风格（性格驱动，不是模板机器人）
每个角色有 **专属语气词库**，按事件类型触发：

| 角色 | 买地 | 被收租 | 收租 | 入狱 | 抽到好卡 | 破产 |
|---|---|---|---|---|---|---|
| 布丁(橘猫) | 「这块地闻着就香！」 | 「呜呜好心疼小鱼干...」 | 「嘿嘿来收租啦~」 | 「不是我干的！冤枉！」 | «太棒了喵!» | «完蛋了肚子都饿了...» |
| 糯米(萨摩耶) | «好耶!新地盘!» | «呜呜呜...好难过...» | «谢谢惠顾汪~» | «我乖乖蹲着...» | «好幸运!» | «我不玩了呜呜呜...» |
| 可可(黑猫) | «哼,这块地值.» | «切,小钱.» | «该交的总是要交的.» | «无聊.» | «哼,还行.» | «...不可能.» |
| 团子(柯基) | «哇塞这地好棒!» | «呜呜我的零花钱!» | «嘿嘿来钱啦!» | «呜呜我好乖的!» | «太棒啦!» | «呜呜呜我要回家了...» |

- **聊天频率**：不是每个事件都说，40-60% 概率说话
- **不同事件组合**：连续两次被收租时第二次语气更急
- **对用户特殊**：AI 对用户玩家有额外调侃（「你运气也太好了吧」「哼下次一定赢你」）

#### 3.4 AI 思考展示
- 回合开始时在角色头像旁显示思考气泡：「在想要不要买...」「在数小鱼干...」「哼让我看看...」
- 决策完成后气泡消失，执行动作
- 用户回合不显示思考气泡

### 4. 动画与特效（Three.js）
- **3D 骰子**：掷骰时两个 3D 骰子在屏幕中央翻滚落下
- **移动粒子**：棋子移动时留下猫爪/狗爪脚印
- **事件特效**：
  - 买地：金币飞溅 + 房屋升起动画
  - 升级：彩虹光芒 + 房屋变形
  - 入狱：乌云 + 铁窗
  - 破产：爆炸 + 碎裂
  - 胜利：彩带 + 爱心雨
- **背景粒子**：轻微漂浮的云朵/猫爪/爱心（可选）
