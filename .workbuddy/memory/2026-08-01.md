## 娃娃机：抓取判定 bug 修复（用户反馈"很准却抓不到 + 钩子不往下"）
- **致命 bug**：`clawMachineStore.dropClaw()` 第一行 `if (clawState.value !== 'idle') return null`，但 `ClawMachine.vue` 的 `handleDrop()` 在调用 `dropClaw` 之前已 `setClawState('dropping')`，导致 `dropClaw` 永远 `return null` —— 抓取判定从未执行，结果恒为"没抓到"。用户再准也抓不到。
  - 修法：把守卫改为 `if (clawState.value === 'grabbing' || clawState.value === 'rising') return null`（只防抓取/上升阶段重复结算）。
- **钩子不往下（视觉）**：爪子静止 `clawY=26`，但天花板遮罩盖到 34%，爪子静止时整个藏在天花板后，按下勾闪一下又缩回去，看着像"没下去/下不去"。
  - 修法：`selectMachine / startGame / resetSession` 及 `clawY` ref 初始值全部 26 → **44**（始终在天花板下方可见）；`animateClawRise` 回位目标 26 → 44。
- **手感**：自己玩对齐度权重 `alignment * 0.25` → `0.5`；`baseRate` 0.25→0.3；`findNearestDoll` 抓取半径 13→15%。现在"对准"大概率抓到。
- **动画卡顿**：爪子 `transition` 原 `top 0.05s linear`（每帧跟 rAF 打架）→ 改为动画期间 `transition:'none'`（rAF 直驱），静止时 `left 0.12s ease-out`（左右按键平滑）。
